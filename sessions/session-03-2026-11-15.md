# Session 03 – Projektinstruktioner och promptmall

**Datum:** 15 november 2026

## Mål

Börja bygga själva riggen genom att skapa projektinstruktioner till Claude Code och en promptmall som kan användas till olika uppgifter.

## Arbetet med CLAUDE.md

Jag har utgått från min tidigare planering och det jag lärde mig i förra delkursen när jag arbetade med instruktionerna till Claude Code.

Jag ville framför allt få med hur viktigt det är att ge AI en tydlig roll, rätt kontext och instruktioner om vad den ska göra. Det var också viktigt för mig att dela upp arbetet i mindre delar så att jag kan kontrollera resultatet innan nästa steg påbörjas.

Jag har använt ChatGPT som bollplank för att diskutera mina tankar, få hjälp att formulera dem tydligare och få texten korrekt formaterad i Markdown.

## Första testet med Claude Code

Jag startade Claude Code för att kontrollera att instruktionerna fungerade.

Claude läste projektplanen och den senaste sessionsloggen och kunde sammanfatta var arbetet hade avslutats.

Den upptäckte också att texten i `CLAUDE.md` hade blivit inklistrad två gånger. Det hade jag missat.

Jag godkände att Claude fick rätta dubbleringen, skapa `docs/prompt-template.md` och korrigera filnamnet `PLAN.md` i Session 02.
